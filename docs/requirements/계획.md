### F-016: 계획 달력(첫 화면) + 설정의 계획 편집
- **설명**: 설정에서 매일 할 계획을 넣고, 달력에서 오늘·그날을 눌러 했는지 체크한다. 앱을 켜면 계획 달력이 먼저 열린다.
- **기존판과 달라진 것**: 재전송 알림이 없으므로 "알림으로 열면 붙여넣기 화면 그대로"가 없다 — 앱 아이콘으로 켜면 늘 계획 화면이 열린다.
  설정 화면은 **계획 줄 둘만** 갖는다.
  **붙여넣기 화면이 없다**(2026-11-19 숨김 → 2026-11-21 채록에서 갈라지며 소스째 없앰, `REQUIREMENTS.md` '채록에서 갈라짐'): 계획 화면이 맨 밑 화면이라 뒤로 = 앱 닫힘.
- **결정**(기존판 2026-11-08 사용자, 그대로):
  ① 저장 = `files/plans/plans.json` ② 계획 목록을 바꾸면 **오늘부터** 적용, 지난 날의 목록·체크는 그대로(목록 이력을 '적용 시작 날짜'별로 보관)
  ③ 체크는 **오늘과 지난 날만**, 미래 날짜는 보기만 ④ 첫 화면 = 계획 달력. 뒤로 → 앱 닫힘
- **모양**: 계획 화면 = 월 달력(일요일 시작, 이전·다음 달) + 날짜 칸에 "한 수/전체"(한 만큼 옅은 하늘색 → 다 하면 스카이 블루로 한 개마다 고르게 진해짐,
  다크는 어두운 남색에서 밝아짐 · 0은 색 없음 · 미래는 표시 없음), 오늘 테두리, 고른 날 진한 테두리 → 아래에 그날 체크 목록 + "N / M 완료" /
  설정 편집 화면 = 추가·이름 바꾸기·지우기·끌어서 순서(줄 아무 데나 길게 눌러 끌기 + 왼쪽 손잡이는 바로 끌기), "바꾼 목록은 오늘부터 적용됩니다…" 안내
- **가정**: 이름은 앞뒤 공백 제거, 빈 이름은 추가 안 함 · 최대 30개 · 40자 · 같은 이름(공백·대소문자 무시) 금지 / 이름을 바꿔도 같은 항목(체크 유지) /
  첫 목록을 넣기 전 날짜는 "계획 없음" / 날짜 = 폰 현지 날짜 / 알림(리마인더)은 안 함 / 로그에 계획 이름을 남기지 않는다(건수만)

  - (사용자 실테스트) 달력 모양·색·오늘 테두리·날짜 누르기·체크 / 설정 화면(계획 두 줄뿐) 모양 · 편집(추가·이름 바꾸기·지우기·순서) /

  ③ 보류는 **오늘과 지난 날만**(체크와 같은 규칙), 미래 날짜는 보기만

  항목 id로 기록하므로 이름을 바꿔도 보류 유지, 그날 목록에서 지운 항목의 보류는 세지 않는다 / 그날 전부 보류면 칸에 "0/0"(색 없음)

### F-026: DO · DON'T
- **설명**: 계획을 DO(하기)와 DON'T(안 하기)로 나눈다 — 설정에서 먼저 나누고, 계획 화면 목록과 달력도 둘로.
- **결정**(기존판 2026-11-15 사용자, 그대로): ① 이름 = **DO · DON'T** ② DON'T의 체크 = **지켰다** ③ 그날 목록은 **위아래**(위 DO, 아래 DON'T, 묶음마다 제목·"N / M")
  ④ 달력 칸은 위 파란색(DO)·아래 빨간색(DON'T) — 빨간색은 **하나도 안 지켰으면 가장 짙고, 지킬수록 옅어져 다 지키면 색 없음**
  ⑤ 그날 목록에 한쪽만 있으면 **있는 쪽이 칸 전체**
- **가정**: 항목에 종류(`kind`: `do`·`dont`) — 키가 없는 항목은 DO, 모르는 값이면 깨진 파일로 본다(저장·체크 거부 — 덮어써서 잃지 않게) /
  설정 편집 화면을 DO·DON'T 두 묶음으로(묶음마다 추가 칸, 순서는 묶음 안에서) / 최대 30개·같은 이름 금지는 두 묶음 합쳐서 /
  종류 바꾸기는 안 함 — 지우고 새로 넣는다 / 보류(F-025)는 DON'T에도 같다 / DON'T를 전부 보류한 날은 아래 반쪽 색 없음 /
  미래 날짜는 두 쪽 모두 표시 없음 / 말풍선 머리에 "DO a/b · DON'T c/d"(없는 쪽은 뺌)
- **수용 기준**(테스트: `plans_test` · `plan_screen_test`):
  - [x] DO [운동, 독서] + DON'T [야식] 저장 → 다시 열어도 종류 그대로, 종류별 집계 DO (0, 2) · DON'T (0, 1)
  - [x] `kind` 키 없는 항목 → DO / 모르는 `kind` 값 → 깨진 파일(저장 거부, 파일 그대로)
  - [x] 이름 바꾸기·순서 바꾸기(종류를 모르는 저장 호출)도 종류를 그대로 둔다
  - [x] 같은 이름은 종류가 달라도 거부
  - [x] DON'T 체크 = 지켰다 — '야식' 체크 → DON'T (1, 1), 보류하면 (0, 0)
  - [x] 화면: 그날 목록이 DO 묶음 위·DON'T 묶음 아래, 묶음마다 "N / M" / DON'T 항목이 없으면 DON'T 묶음 없음
  - [x] 설정 편집: DON'T 칸에 추가 → DON'T 묶음에 들어가고 저장된 종류가 dont
  - (사용자 실테스트) 달력 칸 위아래 색(파랑 진해짐 · 빨강 옅어짐)·한쪽만 있는 날 칸 전체·말풍선·설정 두 묶음 모양·다크 모드
- **바뀜**(2026-11-24 사용자 — 채록 기존판에서 결정 '오늘부터 새 규칙', f05883d를 같은 날 옮김): DON'T는 **기본 지킴** — 그날 아침부터 모두 체크(예: 7/7), 어기면 그 항목을 눌러 체크를 푼다(못 지킴).
  설정 변경 없음. 앱을 켠 날부터 적용, 지난 날은 예전 체크 그대로(체크한 것만 지킴 — 달력·통계의 지난 기록 불변)
  - **가정**: 저장 = 같은 `plans.json`에 `dont_default_from`(새 규칙 시작 날짜)·`missed`(날짜 → 어긴 DON'T id) 키 추가(SCHEMA 2026-11-24) —
    키가 없는 옛 파일은 앱을 켤 때 그날로 `dont_default_from`을 적는다 / 미래 날짜는 기본 지킴 표시 없음(보기만 — 오늘이 되면 체크) /
