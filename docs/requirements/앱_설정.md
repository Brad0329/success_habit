### F-102: 홈 화면 위젯 — 보기 전용, 크기 조절 위젯 하나
- **왜**(2026-11-26 사용자): "혹시 위젯을 이용할 수도 있을까?" → "보기 전용으로" → 목업 → "1번으로, 목업 그대로 진행"
- **결정**(2026-11-26 사용자): 보기 전용(체크는 앱에서) / 위젯 **하나**, 크기를 바꾸면 모양이 바뀜(Android 12 이상 — 사용자 폰 API 37) / 모양 = 목업 A(큰)·B(작은)·C(날짜 지남) 그대로
- **가정**:
  - 큰 모양(4×2쯤): 날짜 "오늘 · 11월 26일 (목)" + '성공습관' / 정체성 문장 첫 줄(없으면 줄 없음) / DO·DON'T 막대 + "3/5"(그 종류가 없으면 줄 없음) /
    맨 아래 "🔥 운동 12일"(오늘 해야 하는 항목 중 연속이 가장 긴 것 — 같으면 목록 순서 앞, 0이면 없음) · "어제 놓침 N개"(직전 놓침 강조가 붙은 항목 수, 0이면 없음)
  - 작은 모양(2×2쯤): 날짜 · DO 크게 · DON'T 작게
  - 날짜가 지난 요약(자정 뒤 앱을 아직 안 엶): 지금 날짜 + 정체성 문장 + "새 하루예요. 눌러서 오늘 계획을 여세요" + "어제 · DO 4/5 · DON'T 7/7"(이틀 이상 지났으면 '어제' 대신 그 날짜)
  - 오늘 계획이 없거나 깨진 파일: "눌러서 계획을 넣으세요"
  - 누르면 앱이 열린다(계획 화면) / 위젯은 자정에 다시 그린다(정확한 알람이 아니라 몇 분 늦을 수 있다 — 권한 없음) / Android 11 이하는 큰 모양만
  - 계산은 앱(Dart)이 하고 `widget/today.json`(SCHEMA 2026-11-26)에 보일 글 그대로 쓴다 — 위젯(Kotlin)은 날짜 판단(요약이 오늘·어제 것인가, 날짜 글)과
    DON'T만 있는 날의 작은 모양만 한다(계획 규칙 두 구현 없음 — 날짜 형식·키·값 타입은 `widget_contract_test`가 대조)
  - 다크 모드 = 시스템 설정 / 권한·새 의존성 없음
