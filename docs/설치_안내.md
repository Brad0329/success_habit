# 성공습관 설치 안내

매일 할 계획을 정해 두고, 달력에서 그날 했는지 체크하는 안드로이드 앱입니다.
플레이 스토어에 없는 앱이라 APK 파일을 직접 받아 설치합니다.

## ⚠ 먼저 알아 둘 것 — 계획은 이 폰 안에만 있습니다

- 계획·체크·하루 평가는 **폰 안에만** 저장됩니다. 서버·로그인·백업이 없습니다.
- 그래서 **앱을 지우거나, 폰을 바꾸거나 잃어버리면 계획이 모두 사라지고 되찾을 수 없습니다.**
- 새 버전을 받으면 **지우지 말고 그 위에 바로 설치**하세요. 그래야 계획이 남습니다.
  설치가 거부되면 지우지 말고 APK를 준 사람에게 물어보세요.

## 설치

1. 받은 성공습관 APK 파일(`.apk`)을 폰에서 엽니다(카카오톡·메일·브라우저로 받은 파일).
2. "출처를 알 수 없는 앱" 안내가 뜨면 **설정 → 이 출처 허용**을 켜고 돌아옵니다.
   (설치가 끝나면 다시 꺼도 됩니다.)
3. **설치**를 누릅니다.
4. "Play 프로텍트" 경고가 뜨면 **세부정보 → 무시하고 설치**(또는 "그래도 설치")를 누릅니다.
   스토어를 거치지 않은 앱이라 뜨는 경고입니다.

## 이 앱이 하지 않는 것

- 인터넷을 쓰지 않습니다(권한 자체가 없습니다).
- 알림·마이크·사진·연락처 등 어떤 권한도 요청하지 않습니다.
- 광고·로그인·데이터 수집이 없습니다.
