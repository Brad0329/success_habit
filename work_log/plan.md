# 채록 폰 전용판 전체 계획 (단일 원본)

> PLAN MODE에서 최초 작성/주요 변경 시 갱신. Phase 완료 시 메인 agent가 체크박스 `[x]` + 완료일.
> `Phase_XXX.md`는 실패한 접근·버린 대안이 있을 때만 만든다.

## 시스템 개요
- 폰에서 본 글·링크·사진·문서·녹음을 모으고, AI가 분류·정리하고, 모은 것을 놓고 AI와 대화하는 개인 안드로이드 앱.
  계획 달력과 외울 문장 보관함이 함께 있다. 폰 주인 혼자 쓰고, 친구에게 APK로 나눠 준다.
  기존 「채록」(`C:\Users\user\Documents\privaterecord`, 읽기 전용 참조)을 폰 전용으로 다시 만든다.
  (요구사항 상세는 docs/REQUIREMENTS.md)

## 아키텍처
- **스택**: Flutter(안드로이드) + Kotlin 공유 액티비티. 기존판 기준 Dart ^3.9.2 / Flutter 3.35.
- **저장**: 앱 전용 폴더의 파일 나무 하나(데이터베이스 없음). 형식은 docs/SCHEMA.md.
  **Google Drive·OAuth·로그인이 앱에 전혀 없고, 백업·내보내기도 없다.**
- **옮기는 방법**: 기존판은 Drive 경계가 인터페이스 네 개(`DriveStore`·`DriveReader`·`DriveCreator`·`DriveDeleter`)로 이미 나뉘어 있고
  조립이 두 곳(`main.dart`·`background.dart`)뿐이다. 그 자리에 폰 폴더 구현을 끼우면 목록·분류·대화·지우기 로직이 거의 그대로 돈다.
  걷어내는 덩어리: 임시 보관→업로드→MD5 대조(`sender`의 업로드부·`pending`·업로드 작업), 계정·OAuth(`drive.dart`·`drive_account.dart`·`account_settings.dart`·`setup`의 Drive 단계·Kotlin `chooseAccount`), 목록 캐시의 증분 판정, 이미지 보관(`photo_cache`).
  의존성 `google_sign_in`·`googleapis`는 넣지 않는다.
- **실행 주체 셋**: 메인 화면 엔진 / 공유 엔진(화면 없이 받기) / 백그라운드 분류 작업(workmanager). 셋이 같은 저장소에 쓴다 —
  파일 쓰는 곳 등록부(`file_writers_test`)로 주체를 고정한다.
- **외부 연동**: Anthropic·Google Gemini(사용자 키), youtube.com(자막·플레이어), 글자 수집기 서버(설정에 주소를 넣은 사람만).
