# 채록 폰 전용판 전체 계획 (단일 원본)

> PLAN MODE에서 최초 작성/주요 변경 시 갱신. Phase 완료 시 메인 agent가 체크박스 `[x]` + 완료일.
> `Phase_XXX.md`는 실패한 접근·버린 대안이 있을 때만 만든다.

## 시스템 개요
- 폰에서 본 글·링크·사진·문서·녹음을 모으고, AI가 분류·정리하고, 모은 것을 놓고 AI와 대화하는 개인 안드로이드 앱.
  계획 달력과 외울 문장 보관함이 함께 있다. 폰 주인 혼자 쓰고, 친구에게 APK로 나눠 준다.
  기존 「채록」(`C:\Users\user\Documents\privaterecord`, 읽기 전용 참조)을 폰 전용으로 다시 만든다.
  (요구사항 상세는 docs/REQUIREMENTS.md)

## 아키텍처
- **스택**: Flutter(안드로이드) + Kotlin 공유 액티비티. 기존판 기준 Dart ^3.9.2 / Flutter 3.35.
- **저장**: 앱 전용 폴더의 파일 나무 하나(데이터베이스 없음). 형식은 docs/SCHEMA.md.
  폰의 나무 = Drive 백업의 나무 = 내보내기 zip의 나무.
- **옮기는 방법**: 기존판은 Drive 경계가 인터페이스 네 개(`DriveStore`·`DriveReader`·`DriveCreator`·`DriveDeleter`)로 이미 나뉘어 있고
  조립이 두 곳(`main.dart`·`background.dart`)뿐이다. 그 자리에 폰 폴더 구현을 끼우면 목록·분류·대화·지우기 로직이 거의 그대로 돈다.
  걷어내는 덩어리: 임시 보관→업로드→MD5 대조(`sender`의 업로드부·`pending`·업로드 작업), 계정·OAuth, 목록 캐시의 증분 판정, 이미지 보관(`photo_cache`).
- **실행 주체 셋**: 메인 화면 엔진 / 공유 엔진(화면 없이 받기) / 백그라운드 분류 작업(workmanager). 셋이 같은 저장소에 쓴다 —
  파일 쓰는 곳 등록부(`file_writers_test`)로 주체를 고정한다.
- **외부 연동**: Anthropic·Google Gemini(사용자 키), youtube.com(자막·플레이어), 글자 수집기 서버(설정에 주소를 넣은 사람만),
  Google Drive(백업을 켠 사람만, `drive.file`).

## 결정된 것 / 미정인 것

**확정** (모두 사용자 결정 2026-11-19)
- 폰 전용. 기본 사용에 Drive·OAuth·PC 없음. 원본은 **앱 전용 폴더**(공유 저장소 아님 — 권한 제약으로 구현이 복잡해져서).
- 앱 이름 '채록', 패키지 `com.brad0329.chaerok.phone`(기존 `com.brad0329.chaerok`와 함께 깔 수 있게).
- 배포는 APK 직접 전달. 스토어 없음.
- 기존 Drive 수집물은 가져오지 않고 새로 시작(가져오기는 보류 — 저장 형식을 같게 둬서 나중에 붙일 수 있다).
- '채록 + 메모'(ShareMemoActivity)는 옮기지 않는다.
- Drive 백업: 선택 기능 / 앱을 열 때 자동 + '지금 백업' 버튼(백그라운드 작업 아님 — 기존판에서 갤럭시가 백그라운드 업로드를 멈췄다) /
  폰에서 지우면 Drive 사본도 지운다 / 복원 넣는다 / 범위는 수집물 + 대화 + 계획 + 외울 문장 + 카테고리.
- 내보내기 zip을 넣는다(Google 로그인 없이 되는 안전망).
- 글자 수집기(F-012) 서버 주소는 코드에 두지 않고 설정 칸으로. 비우면 기능이 안 보인다.
- 원격: 비공개 GitHub `Brad0329/chaerok_phone`(SSH 별칭 `github-brad`).
- git에 안 들어가는 것: 지금은 없다(`.env` 없음 — 키는 사용자가 앱 설정에 넣는다). **릴리스 서명 키가 생기면 보관 위치를 그때 정한다(Phase 009)**.
